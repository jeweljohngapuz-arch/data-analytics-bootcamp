What this is

Practice tool. Companion to the Dashboard. Drill BI terms, technical concepts, stakeholder scenarios, and interview answers. 20–30 min/day max — your main work is on the Dashboard.

How a session goes

1
Pick a stage from home. 4 to choose from. Locked stages show what day they unlock.
2
Answer questions. Multiple choice, fill-in-the-blank, STAR (Situation-Task-Action-Result), or short written.
3
Read the Analyst Context card after each answer. What it is · when to use · example · how it works in practice. This is the actual learning.
4
Lose all 3 hearts → run ends. Tap "Try Again" to restart the stage. Your streak + concept misses still save.
Today's Context banner (blue, top of home): appears when the Dashboard has assigned today's bootcamp day. Tap "Start Today's Drill" to jump straight into questions matched to today's topic.

What gets tracked

  • Day streak — consecutive days you practiced (1+ question)
  • Combo — consecutive correct answers in the current run
  • Per-concept misses — feeds Dashboard's Weak Concept Radar
  • Review log — last 100 answers, downloadable as .txt

Hearts ❤️

Start each stage with 3 hearts. Each wrong answer loses one. Lose all 3 → "Out of Hearts" screen. No penalty in real life — just restart and try again.

Why hearts? They force you to slow down and read the question instead of guessing. Three misses in a row means you should stop and look at the Analyst Context cards from those misses.

Streak 🔥

Updates when you answer at least 1 question in a day. Daily streak, not per-stage. Missing a day breaks it.

Combo ⚡

Counts consecutive correct answers in the current run. Shows up after combo 2. Wrong answer resets it to 0.

Question types

TypeHow to answer
MC (multiple choice)Tap one option. Lock in. See result.
FillType the word/phrase. Case-insensitive. Partial matches accepted from a list.
STARType your S, T, A, R fields. Submit when R is at least 10 chars. Then read the model STAR.
WriteFree-form answer, min 15 chars. Compare to the model answer after.

Hints 💡

Tap the lightbulb (when available) to see a hint. No penalty.

Spiral Deck (spaced repetition)

If you see a "spiral deck" option, it surfaces concepts you've rated weak in past sessions. After answering, rate your recall — those ratings drive what comes back.

Why stages are gated

You don't need Stakeholder Sim until you've built enough technical skill to have something to communicate. The Dashboard's current day controls which stages unlock here.

A stage is locked: tap it anyway — a tooltip shows the unlock day. The Dashboard's current day determines this; if you're past day 28, Stakeholder Sim opens.

How questions are picked

Vocab + Tech: shuffled within sub-categories, kept in step order so concepts build on each other. Sim: scenarios in fixed order, each with multi-step decisions. Interview: shuffled question pool.

What Drill Mode is

A filtered version of the Suite. Instead of all questions across all sub-categories, you see only questions about one specific weak concept — JOIN logic, DAX filter context, NULL handling, etc.

How to activate it

  1. Open the Dashboard in another tab.
  2. Go to 🪫 Weak Concept Radar. Your top 3 weakest concepts show up there.
  3. Click 🎯 Drill this concept on any of them.
  4. The Suite (this app) opens in a new tab with a red drill banner on the home screen.
  5. Start any stage. The queue is filtered to only that concept's questions.

How to exit it

Tap ✕ Exit Drill Mode in the red banner. Or pick a different concept from the Dashboard — it auto-replaces.

Stage titles change in drill mode. "LANGUAGE LAB" becomes "LANGUAGE LAB · DRILL" so you always know you're in filtered mode.

When to use it

  • 3+ misses on one concept — that's the threshold. Drill until misses drop.
  • Before an interview — drill your weakest topic the day before.
  • After a project walkthrough rep — if Gemini caught you on a specific area, drill that.
If a stage has zero matching questions for your drill concept, the full pool plays instead. The 20-concept classifier covers most BI questions, but rare ones can slip through.

Where your Suite data lives

Two browser localStorage keys:

  • bi3 — your Suite state: streak, scores, weak list, review log, recall ratings
  • jewel_weak_concepts_v1 — concept-by-concept miss tracking (shared with Dashboard)
The Suite has no export function. It's reinforcement, not the source of truth. If you switch laptops, your Suite progress (streak / hearts) resets — but the Dashboard's Weak Concept Radar data does get carried via the shared key if you export from Dashboard there.

Streak protection

If you miss a day, the streak goes to 0 next time you open the Suite. There's no streak freeze. The point is consistency — if you miss, start a new streak.

Download review log

From home: tap the review log button to download bi_review.txt with your last 100 answers. Useful for spotting patterns or for showing recruiters the practice habit.

The Suite is the smaller half

This file (the Suite) is for reinforcement. The Dashboard is where the actual bootcamp lives — daily lessons, evidence logging, portfolio tracking, job applications, runway control.

Open the Dashboard

From any home screen, tap the "← Back to Day Plan" link inside the blue Today's Context banner. Or if you didn't come from the Dashboard, paste the Dashboard URL.

The full FAQ lives there

The Dashboard has its own ? button (bottom-right). 8 tabs covering: Quick Start · Daily Loop · Sections · Proof Loop · How To · Save Work · Rules · Suite. Open that for the system-level docs.

How the two files talk

DirectionWhat flows
Dashboard → SuiteToday's day context (for the blue banner) · Drill concept (for filtering questions)
Suite → DashboardConcept-by-concept miss data (feeds Weak Concept Radar)
Tip: open both files in separate tabs while you work. Cross-tab sync is real-time — drill a concept on Dashboard, the Suite's banner appears within milliseconds.

Daily order of operations

  1. Open Dashboard. Open today's day card. Do the build work.
  2. Mark Day Complete. Log evidence.
  3. Then open Suite for 20–30 min reinforcement.
  4. If Weak Concept Radar shows a top 3 miss, drill it.
  5. End-of-week: fill Weekly Market Validation in Dashboard. Export progress to OneDrive.
